# 🖼️ صور عشوائية — Random Images Site

موقع بسيط جداً: **زر واحد** فقط («فتح الصورة»)، وعند الضغط عليه تظهر **صورة عشوائية من مجموعة كبيرة** تُجلب **مباشرة من الإنترنت** — لا يُخزَّن أي شيء على الاستضافة.

| | الرابط |
|---|---|
| 🌍 **الموقع المباشر** | https://random-images-site.vercel.app |
| 📦 **المستودع** | https://github.com/elias0878/random-images-site |

## المصادر (المجموعة الكبيرة)

يُحدَّد المصدر من ملف **`config.js`** بتغيير سطر واحد — ولا يظهر منه شيء في الواجهة:

```js
window.SITE_CONFIG = { source: 'picsum' };   // أو 'wikimedia' أو 'folder'
```

| المصدر | الحجم | الربط المباشر | CORS | ملاحظات |
|---|---|---|---|---|
| **`picsum`** *(الافتراضي)* | **~993 صورة** | ✅ مسموح ومشجّع | ✅ `*` | صور Unsplash، بلا حدود، مخصّص للربط المباشر |
| `wikimedia` | ~176–330 صورة | ✅ مسموح | ✅ `*` | صور مختارة حرة الاستخدام، لكن الـ API يحدّ الطلبات المتكرّرة |
| `folder` | حسب مجلد `images/` | — | — | صور من مستودعك (تُخزَّن في المستودع) |

جميع الصور **تُعرض مباشرة من مصدرها** في كل مرة (`<img src>` من نطاق المصدر) — لا تُنزَّل ولا تُخزَّن على Vercel ولا في المستودع.

### إعدادات المصادر في `config.js`

```js
picsum: {
  pages: 10,          // 10 × 100 = ~993 صورة
  limitPerPage: 100,
  width: 1600,        // أبعاد الصورة المعروضة
  height: 1000,
  cacheHours: 12      // مدة الاحتفاظ بالقائمة في ذاكرة المتصفح
}
```

لتوسيع القائمة: ارفع `pages` (الحد الأقصى المتاح فعلياً 10 صفحات = 993 صورة).
لإضافة تصنيفات ويكيميديا: أضف أسماء تصنيفات إلى `wikimedia.categories`.

## كيف يعمل؟

```
config.js            ← تحديد المصدر (المصدر الافتراضي: Picsum)
    ↓
app.js               ← يجلب قائمة كبيرة من الصور (ويحفظها في ذاكرة المتصفح 12 ساعة)
    ↓
الضغط على الزر       ← اختيار رقم عشوائي + جلب الصورة مباشرة من المصدر وعرضها
```

- لا قاعدة بيانات · لا تسجيل دخول · لا سيرفر · لا تخزين للملفات
- تحميل مسبق للقائمة في الخلفية حتى تكون أول ضغطة سريعة
- لا تُعرض نفس الصورة مرتين على التوالي
- خطة بديلة: لو فشل جلب القائمة، يجلب صورة عشوائية مباشرة بلا قائمة

## إضافة صورك الخاصة (اختياري)

بدّل المصدر إلى `'folder'` في `config.js`، ثم:

### من موقع GitHub (الأسهل)
1. افتح مجلد **images**: https://github.com/elias0878/random-images-site/tree/main/images
2. **Add file → Upload files** واسحب صورك، ثم **Commit changes**.
3. 🤖 GitHub Action يحدّث `images.json` تلقائياً · 🚀 Vercel ينشر خلال دقيقة.

### من جهازك
```bash
cp ~/pictures/* images/
npm run build && git add -A && git commit -m "صور جديدة" && git push
```

### من مجلد أو ملف مضغوط
```bash
./scripts/add-images.sh /path/to/folder-or-zip
```

### تسريع الموقع
```bash
pip install Pillow
python3 scripts/optimize-images.py --max 1920 --quality 82
```

## ملاحظات مهمة

**عن perchance.org:** لا يمكن استخدامه كمصدر لهذا الموقع، لأسباب تقنية بحتة:
- لا يوجد API رسمي عام (السيرفر يعتمد على الإعلانات، ولا يوفّرون واجهة للمطوّرين).
- صفحات المولّدات **لا ترسل ترويسات CORS**، فلا يستطيع المتصفح جلب شيء منها.
- الصور المولَّدة تُعاد كـ `data:image/jpeg;base64` داخل iframes متداخلة — لا يوجد رابط صورة مباشر يمكن ربطه.
- إضافة «random image» في perchance كانت تعتمد على خدمة `source.unsplash.com` وهي **متوقفة نهائياً** (ترجع 503).

**عن Wikimedia:** الخدمة تحدّ الطلبات المتكرّرة السريعة. الكود يضيف مهلة بين الطلبات ويتوقف بلطف عند الحاجة. لو لم تُحمَّل القائمة، أعد المحاولة بعد قليل أو استخدم `picsum`.

**الترخيص:** Picsum = صور Unsplash (مجانية الاستخدام). ويكيميديا = رخص حرة (CC). يُعرض اسم المصور في سطر صغير أسفل الصورة.
