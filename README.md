## البنية

```
index.html          الواجهة الواحدة (RTL)
styles.css          التنسيق (فاتح/داكن تلقائي)
js/ui.js            محرّك الأدوات: عناصر، حقول، مخرجات، ملفات، صور
js/app.js           الراوتر + البحث + التصنيفات + المفضلة
js/tools/*.js       الأدوات مقسّمة حسب التصنيف
api/translate.js    واجهة الترجمة على نطاق الموقع (لأن المتصفح لا يستطيع الاتصال بمحرّك الترجمة مباشرة)
test/smoke.js       اختبار: تسجيل ورسم كل الأدوات داخل jsdom
test/serve.js       سيرفر تطوير محلي (يحاكي /api أيضاً)
```

## المبادئ
1. **لا شيء شكلي**: كل أداة تنفّذ إجراءً حقيقياً يمكن التحقق منه.
2. **المعالجة محلياً أولاً**: الصور والنصوص والملفات تُعالج في المتصفح. لا رفع، ولا تخزين، ولا تتبّع.
3. **الشبكة عند الضرورة فقط**: الترجمة وأسعار الصرف فقط، وتمرّ عبر وسيط الموقع لأن المتصفح يمنع الاتصال المباشر بمصادرها (CORS).
4. **بلا مكتبات خارجية**: صفر اعتماديات وقت التشغيل — JavaScript وCanvas فقط.

## التشغيل محلياً

```bash
node test/serve.js      # ثم افتح http://localhost:3000
node test/smoke.js      # اختبار تسجيل ورسم كل الأدوات (يحتاج jsdom)
```
